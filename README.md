
# Deploy a 3-Tier Book Review App on AWS

👋 Hi, I'm **Amine**, an aspiring Cloud & DevOps Engineer.

This repository is my end-to-end project where I took a Book Review Application and focused on turning it into a **production-ready, deployable system on AWS**.

---

## About This Project

This is a **full-stack 3-Tier Book Review Application** that allows users to:
- Browse books
- Read reviews written by the community
- Register, login, and submit their own reviews (only authenticated users can write reviews)

The application follows clean **three-tier architecture**:
- **Frontend** (Presentation Layer)
- **Backend** (Business Logic Layer)
- **Database** (Data Layer)

---

## My Role in This Project

I did **not** write the original source code of the application. 

As an aspiring Cloud & DevOps Engineer, my main goal was to take an existing project and focus on what matters most to me: **deployment, automation, documentation, and making the app production-ready on AWS**.

## Tech Stack

**Frontend:** Next.js 14, Tailwind CSS, Axios, React Context  
**Backend:** Node.js, Express.js, Sequelize, MySQL, JWT  
**DevOps:** Docker, Docker Compose, Ansible, PM2, AWS (EC2, RDS, etc.)
